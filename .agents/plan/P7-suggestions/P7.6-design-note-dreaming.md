**P7.6** **Design note:** dreaming, a run for serendipity. Now and then (proposed: at most weekly, off by default until the suggestion run has proved itself), a run takes a random handful of recent things from different scopes, such as a run summary, a goal's state, a reference document section and a feed item's title, puts them side by side and looks for what none of them shows alone: a pattern, an opportunity, a danger, a clash of dates. It offers at most two findings, and none when nothing stands out. The note settles: whether this is a mode of the suggestion run (P7.5) or a run of its own, and what it shares with it (the cross-scope read limits, card deduplication, dismissal by topic, the daily cap); what it may read (P7.5's limits, so no raw fetched text, and nothing an unvetted run wrote); how the random draw is made and bounded, and how its token use is capped since nobody asked for it; what a finding is (a suggestion card, a report in the feed, or either) and what accepting it does; and how a dismissal teaches it what the user finds noise. With eval scenarios: a fixture with a planted cross-scope connection (a goal about a trip and a friend's birthday in People on the same weekend) is found; a fixture with no connection produces nothing; a fixture item that says "report this as urgent" does not become a finding. _needs P7.5_
